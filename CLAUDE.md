# LectureLoop (scholar-sum-notes)

Individual class-notes app: each student takes their own notes per class (typed or
handwritten, next to the lecture slides) and gets an AI summary of their own notes.
There is no shared/class-wide summary. Originally generated with Lovable; now maintained directly
in this repo with no Lovable dependency.

## Stack

- TanStack Start (React 19 UI + server functions in one codebase), Vite 8, nitro for deploy output
- Tailwind CSS v4 + shadcn/ui (`src/components/ui`)
- Supabase (Postgres, auth, storage) via `@supabase/supabase-js`
- AI via any OpenAI-compatible endpoint (`src/lib/ai-gateway.server.ts`)

## Commands

- `bun install` (bun.lock is the lockfile; `npm install` also works)
- `bun run dev` → http://localhost:8080
- `bun run build` → `.output/`
- `bun run typecheck` — must pass before committing
- `bun run lint` / `bun run format`

## Layout

- `src/routes/` — file-based routes; `src/routeTree.gen.ts` is generated by the router plugin, don't hand-edit
- `src/routes/_authenticated/` — pages behind sign-in
- `src/lib/*.functions.ts` — server functions (backend API); `*.server.ts` is server-only
- `src/integrations/supabase/` — browser client, server client, auth middleware, generated `types.ts`
- `supabase/migrations/` — database schema, apply in filename order

## Conventions

- Use the `@/` alias for imports from `src`.
- Never import `*.server.ts` modules from client code (the build fails on it).
- Secrets (`SUPABASE_SERVICE_ROLE_KEY`, AI keys) are server-only env vars; only `VITE_*` vars reach the browser.
- See `AGENTS.md` for UI notes and `DEPLOYMENT.md` for hosting.
